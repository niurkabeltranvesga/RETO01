## 💻 2. Aplicación de Escritorio (`AppReto01.exe`)
Es una aplicación independiente para Windows que **no requiere abrir el entorno de desarrollo de MATLAB ni ver el código fuente**.

### 📥 Requisitos para ejecutar la App de Escritorio:
Para que cualquier usuario pueda ejecutar la aplicación sin tener el software de MATLAB instalado, se requiere el motor gratuito **MATLAB Runtime**:

1. **Descargar MATLAB Runtime (Gratuito):**
   - Puedes descargarlo directamente desde el sitio oficial de MathWorks:  
     🔗 [Descargar MATLAB Runtime](https://www.mathworks.com/products/compiler/matlab-runtime.html)
   - *(Asegúrate de instalar la versión correspondiente a la versión de MATLAB con la que se compiló el proyecto).*
2. **Ejecutar la App:**
   - Una vez instalado el Runtime, solo debes hacer doble clic sobre el archivo **`AppReto01.exe`** para abrir la interfaz directamente.

## 📁 Estructura del Repositorio

- `gui/`: Contiene la interfaz gráfica de escritorio y el ejecutable `AppReto01.exe`.
- `src/`: Funciones y módulos de cálculo matemático, generación de reportes y lógica.
- `web/`: Archivos HTML, CSS y JavaScript de la versión web pública.
- `test/`: Pruebas unitarias y validaciones de persistencia y casos de cálculo.
